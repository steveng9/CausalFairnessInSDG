The graphs each fairness mechanism acted on in sweep facct-2026-10-09. Nodes are red when protected, yellow when admissible, blue for the outcome, grey otherwise. A cross marks an edge a mechanism removes: green F for FTU, yellow C for CF, red D for DP.

Causal DAG families: GAN, diffusion, TabPFN

One hand-drawn DAG per dataset, the same for every DAG-based generator, seed and privacy budget. A cut does not delete the edge from training. When the child is sampled, the parent's values are shuffled across rows, so the child no longer depends on that parent. Every cut lands on an edge into the outcome, because the code cuts each offending path at its last edge.

Marginal family: the graphs MST chose

MST has no fixed graph. It picks a spanning tree from noisy pairwise measurements, and a mechanism works by refusing candidate edges while the tree is built. Each panel overlays the five seeds at ε = 1: a thick line was chosen in every seed, a thin line shows its count. A dashed line with a cross was chosen without the mechanism and never with it. A purple line was chosen only with the mechanism.
